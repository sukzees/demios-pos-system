# อัปเดตขนาดกระดาษเป็น 80mm สำหรับ Kitchen Bill และ Void Bill

## สรุปการเปลี่ยนแปลง

อัปเดตระบบพิมพ์ตั๋วครัวและตั๋วยกเลิกให้รองรับกระดาษขนาด 80mm (48 ตัวอักษรต่อบรรทัด)

## ไฟล์ที่แก้ไข

### 1. `app/pos/page.tsx`

#### Kitchen Ticket Content
- **ฟังก์ชัน**: `createKitchenTicketContent()`
- **เปลี่ยน**: เส้นแบ่ง (separator) จาก 31 ตัวอักษร เป็น 48 ตัวอักษร
- **เดิม**: `═══════════════════════════════` (31 chars)
- **ใหม่**: `================================================` (48 chars)
- **เหตุผล**: กระดาษ 80mm รองรับ 48 ตัวอักษรต่อบรรทัด

#### Cancel Ticket Content
- **ฟังก์ชัน**: `createCancelTicketContent()`
- **เปลี่ยน**: เส้นแบ่ง (separator) จาก 31 ตัวอักษร เป็น 48 ตัวอักษร
- **เดิม**: `═══════════════════════════════` (31 chars)
- **ใหม่**: `================================================` (48 chars)

#### API Calls
- **เพิ่ม**: พารามิเตอร์ `paperWidth: '80mm'` ในการเรียก API
- **Kitchen ticket**: ส่ง `paperWidth: '80mm'`
- **Cancel ticket**: ส่ง `paperWidth: '80mm'`

### 2. `app/api/print-network/route.ts`

#### API Endpoint
- **เพิ่ม**: พารามิเตอร์ `paperWidth` (default: '80mm')
- **อัปเดต**: การจัดรูปแบบข้อความสำหรับกระดาษ 80mm
- **เพิ่ม**: การจัดการ section headers (ORDER NOTE, CANCELLED ITEM) ด้วยตัวหนา
- **Return**: ส่งค่า `paperWidth` กลับในผลลัพธ์

## ขนาดกระดาษที่รองรับ

### 80mm Paper
- **ความกว้าง**: 48 ตัวอักษร
- **ใช้สำหรับ**: Kitchen bills, Cancel tickets
- **เส้นแบ่ง**: `================================================` (48 chars)

### 58mm Paper (สำหรับอนาคต)
- **ความกว้าง**: 32 ตัวอักษร
- **เส้นแบ่ง**: `================================` (32 chars)

## รูปแบบตั๋ว 80mm

### Kitchen Ticket
```
================================================
*** Kitchen ***
================================================

Table: T1
Time: 11/05/2026, 10:30:00

================================================

2x  Pad Thai
    Size: Large
    Note: Extra spicy

1x  Tom Yum Soup

================================================

ORDER NOTE:
No peanuts please

================================================

Restaurant Name

```

### Cancel Ticket
```
================================================
*** CANCEL ORDER ***
================================================

Table: T1
Time: 11/05/2026, 10:35:00

================================================

CANCELLED ITEM:

1x  Pad Thai
    Size: Large

================================================

Please discard this item

================================================

Restaurant Name

```

## การจัดรูปแบบข้อความ

### Text Styles
- **Headers** (`***`): Bold + Size 2x2
- **Important Info** (Table, Time): Bold
- **Section Headers** (ORDER NOTE, CANCELLED ITEM): Bold
- **Separators** (`===`): Normal
- **Regular Text**: Normal

### Alignment
- **ทั้งหมด**: Center aligned (ct)

### Font
- **Font A**: Standard ESC/POS font

## ประโยชน์ของกระดาษ 80mm

1. **พื้นที่มากขึ่น**: แสดงข้อมูลได้มากกว่า 58mm
2. **อ่านง่าย**: ตัวอักษรใหญ่ขึ้น ชัดเจนขึ้น
3. **รายละเอียดครบ**: สามารถแสดงชื่อเมนูยาวๆ ได้สบาย
4. **มาตรฐาน**: เป็นขนาดมาตรฐานสำหรับครัว

## การทดสอบ

### ขั้นตอนการทดสอบ
1. เพิ่มเมนูลงในตะกร้า
2. กด "Send to Kitchen"
3. ตรวจสอบตั๋วที่พิมพ์ออกมา:
   - เส้นแบ่งยาว 48 ตัวอักษร
   - ข้อความไม่ล้นออกนอกกระดาษ
   - จัดกึ่งกลางสวยงาม
4. ยกเลิกเมนูที่ส่งครัวแล้ว
5. ตรวจสอบตั๋วยกเลิก:
   - รูปแบบเหมือนตั๋วครัว
   - แสดง "CANCEL ORDER" ชัดเจน

### สิ่งที่ต้องตรวจสอบ
- ✅ เส้นแบ่งยาวพอดี 48 ตัวอักษร
- ✅ ข้อความไม่ล้นออกนอกกระดาษ
- ✅ Headers แสดงเป็นตัวหนาและใหญ่
- ✅ ข้อมูลโต๊ะและเวลาแสดงเป็นตัวหนา
- ✅ รายการเมนูแสดงชัดเจน
- ✅ หมายเหตุแสดงครบถ้วน
- ✅ ตัดกระดาษอัตโนมัติ

## หมายเหตุ

- ระบบตั้งค่าเป็น 80mm เป็นค่าเริ่มต้น
- สามารถเปลี่ยนเป็น 58mm ได้ในอนาคตโดยแก้ `paperWidth` parameter
- เครื่องพิมพ์ต้องรองรับกระดาษ 80mm
- ถ้าใช้กระดาษ 58mm กับการตั้งค่า 80mm ข้อความจะล้นออกนอกกระดาษ

## การปรับแต่งในอนาคต

หากต้องการเปลี่ยนขนาดกระดาษ:

1. แก้ไข `createKitchenTicketContent()` และ `createCancelTicketContent()`
   - เปลี่ยนความยาวของ `separator`
   - 58mm = 32 chars
   - 80mm = 48 chars

2. แก้ไข API calls
   - เปลี่ยน `paperWidth: '80mm'` เป็น `paperWidth: '58mm'`

3. อัปเดต API endpoint
   - ปรับ default value ของ `paperWidth`
