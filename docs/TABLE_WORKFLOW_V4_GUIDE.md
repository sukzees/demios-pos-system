# คู่มือการใช้งานระบบโต๊ะ เวอร์ชัน 4.0

## 🎯 ภาพรวม (Overview)

ระบบโต๊ะเวอร์ชัน 4.0 ได้รับการปรับปรุงเพิ่มเติม:

### ✨ การเปลี่ยนแปลงใหม่ (v4.0)

1. **ส่งไปครัว → เมนูยังอยู่ที่โต๊ะ**
   - เมื่อส่งไปครัวแล้ว เมนูจะไม่หายจากตะกร้า
   - เมนูจะถูก mark เป็น "ส่งครัวแล้ว" (sentToKitchen: true)
   - สามารถเพิ่มเมนูใหม่ต่อได้เรื่อยๆ

2. **ระบบรวมโต๊ะ (Merge Tables)**
   - รวมโต๊ะปัจจุบันเข้ากับโต๊ะอื่น
   - ย้ายรายการทั้งหมดไปโต๊ะใหม่
   - ปล่อยโต๊ะเดิมอัตโนมัติ

3. **ระบบแยกโต๊ะ (Split Table)**
   - เลือกรายการที่ต้องการย้าย
   - ย้ายไปโต๊ะใหม่
   - รายการที่เหลืออยู่ที่โต๊ะเดิม

## 🔄 ขั้นตอนการใช้งาน (Workflow)

### 1. เลือกประเภทการสั่ง (Select Order Type)

เมื่อเปิดหน้า POS หรือคลิก "เลือกโต๊ะ" จะแสดงหน้าต่างให้เลือก:

**2 Tabs:**
- 🍽️ **Dine-In** (นั่งทาน) - เลือกโต๊ะ
- 🛍️ **Takeout** (กลับบ้าน) - สั่งกลับบ้าน

### 2. Tab "Dine-In" (นั่งทาน)

**เลือกโต๊ะ:**
1. เลือก Zone (Indoor, Outdoor, VIP)
2. คลิกโต๊ะที่ต้องการ
3. เริ่มสั่งเมนู

**สถานะโต๊ะ:**
- 🟢 **Available** (ว่าง) - เลือกได้
- 🔴 **Occupied** (มีคนนั่ง) - เลือกได้ (เพื่อเพิ่มเมนู)
- 🟡 **Reserved** (จองแล้ว) - เลือกไม่ได้
- ⚫ **Inactive** (ปิดใช้งาน) - เลือกไม่ได้

### 3. Tab "Takeout" (กลับบ้าน)

**สั่งกลับบ้าน:**
1. คลิก Tab "Takeout"
2. คลิกปุ่ม "Takeout" ใหญ่
3. เริ่มสั่งเมนู

### 4. สั่งเมนู (Order Items)

หลังจากเลือกโต๊ะหรือ Takeout แล้ว:

1. **เลือกเมนู** จากรายการ
2. **คลิกเมนู** เพื่อเพิ่มลงตะกร้า
3. **ปรับจำนวน** ด้วยปุ่ม + / -
4. **เพิ่มหมายเหตุ** (ถ้าต้องการ)

### 5. ส่งไปครัว (Send to Kitchen) 🆕

**ขั้นตอน:**
1. คลิกปุ่ม **"ส่งไปครัว"**
2. รายการจะถูกส่งไปครัว
3. **เมนูยังคงอยู่ในตะกร้า** (ไม่หาย)
4. เมนูจะแสดงสถานะ "ส่งครัวแล้ว"
5. สามารถเพิ่มเมนูใหม่ต่อได้

**หมายเหตุ:**
- ✅ เมนูที่ส่งครัวแล้วจะไม่ถูกล้างเมื่อเปลี่ยนโต๊ะ
- ✅ เมนูที่ส่งครัวแล้วจะไม่ถูกล้างเมื่อกดปุ่ม "กลับไปเลือก"
- ✅ เมนูจะหายเฉพาะเมื่อ Checkout เท่านั้น

### 6. รวมโต๊ะ (Merge Tables) 🆕

**เมื่อไหร่ควรใช้:**
- ลูกค้า 2 โต๊ะต้องการนั่งรวมกัน
- ต้องการรวมบิลเข้าด้วยกัน

**ขั้นตอน:**
1. คลิกปุ่ม **"รวมโต๊ะ"** (Merge Tables)
2. เลือกโต๊ะที่ต้องการรวมเข้า
3. รายการทั้งหมดจะย้ายไปโต๊ะใหม่
4. โต๊ะเดิมจะถูกปล่อยอัตโนมัติ

**ตัวอย่าง:**
```
โต๊ะ T1: Burger x2, Cola x2
โต๊ะ T2: Pizza x1, Salad x1

รวม T1 → T2:
โต๊ะ T2: Burger x2, Cola x2, Pizza x1, Salad x1
โต๊ะ T1: ว่าง (Available)
```

### 7. แยกโต๊ะ (Split Table) 🆕

**เมื่อไหร่ควรใช้:**
- ลูกค้าต้องการแยกบิล
- บางคนต้องการย้ายไปโต๊ะอื่น

**ขั้นตอน:**
1. คลิกปุ่ม **"แยกโต๊ะ"** (Split Table)
2. **เลือกรายการ** ที่ต้องการย้าย (คลิกที่รายการ)
3. **เลือกโต๊ะปลายทาง** ที่จะย้ายไป
4. รายการที่เลือกจะย้ายไปโต๊ะใหม่
5. รายการที่เหลืออยู่ที่โต๊ะเดิม

**ตัวอย่าง:**
```
โต๊ะ T5: Burger x2, Pizza x1, Cola x3

แยกไป T7 (เลือก Pizza x1, Cola x1):
โต๊ะ T5: Burger x2, Cola x2
โต๊ะ T7: Pizza x1, Cola x1
```

### 8. ปุ่มควบคุม (Control Buttons)

**ที่แถบด้านบน:**
- 🔙 **กลับไปเลือก** - กลับไปหน้าเลือก Dine-In/Takeout (ล้างเมนูที่ยังไม่ส่งครัว)
- 🔄 **เปลี่ยนโต๊ะ** - เปลี่ยนโต๊ะ (ล้างเมนูที่ยังไม่ส่งครัว)
- 🔗 **รวมโต๊ะ** - รวมโต๊ะปัจจุบันกับโต๊ะอื่น 🆕
- ✂️ **แยกโต๊ะ** - แยกรายการไปโต๊ะใหม่ 🆕

**ที่ตะกร้า:**
- ⏸️ **พักรายการ** - พักรายการไว้ก่อน
- 🗑️ **ล้างตะกร้า** - ล้างเมนูที่ยังไม่ส่งครัว
- 🍳 **ส่งไปครัว** - ส่งรายการไปครัว (เมนูยังอยู่)

### 9. ชำระเงิน (Checkout)

เมื่อลูกค้าต้องการชำระเงิน:

1. คลิกปุ่ม **"ชำระเงิน"**
2. เลือกวิธีชำระเงิน (เงินสด/โอนเงิน)
3. คลิก **"ยืนยัน"**

**ผลลัพธ์:**
- ✅ บันทึกรายการสั่งซื้อ
- ✅ พิมพ์ใบเสร็จ (ถ้าเปิดใช้งาน)
- ✅ ปล่อยโต๊ะอัตโนมัติ
- ✅ ล้างเมนูทั้งหมด (รวมที่ส่งครัวแล้ว)
- ✅ พร้อมรับลูกค้าคนต่อไป

## 🔍 ตัวอย่างการใช้งาน

### กรณีที่ 1: ลูกค้านั่งทาน + ส่งครัวหลายรอบ

```
1. เลือกโต๊ะ T1
2. สั่งเมนู: Appetizer x2
3. ส่งไปครัว → เมนูยังอยู่ในตะกร้า ✅
4. ลูกค้าสั่งเพิ่ม: Main Course x2
5. ส่งไปครัวอีกครั้ง → เมนูทั้งหมดยังอยู่ ✅
6. ลูกค้าสั่งเพิ่ม: Dessert x1
7. ส่งไปครัวอีกครั้ง
8. ชำระเงิน → ล้างทั้งหมด + ปล่อยโต๊ะ
```

### กรณีที่ 2: รวมโต๊ะ

```
สถานการณ์: ลูกค้า 2 โต๊ะต้องการนั่งรวมกัน

โต๊ะ T3: Burger x2, Cola x2 (ส่งครัวแล้ว)
โต๊ะ T5: Pizza x1, Salad x1 (ส่งครัวแล้ว)

ขั้นตอน:
1. เลือกโต๊ะ T3
2. คลิก "รวมโต๊ะ"
3. เลือกโต๊ะ T5
4. ระบบรวมรายการ:
   โต๊ะ T5: Burger x2, Cola x2, Pizza x1, Salad x1
   โต๊ะ T3: ว่าง (Available)
5. ชำระเงินที่โต๊ะ T5
```

### กรณีที่ 3: แยกโต๊ะ (Split Bill)

```
สถานการณ์: ลูกค้า 4 คนต้องการแยกบิล

โต๊ะ T7: Burger x2, Pizza x1, Cola x4, Fries x2

ขั้นตอน:
1. คลิก "แยกโต๊ะ"
2. เลือกรายการที่จะย้าย:
   ☑ Pizza x1
   ☑ Cola x2
   ☑ Fries x1
3. เลือกโต๊ะปลายทาง: T8
4. ผลลัพธ์:
   โต๊ะ T7: Burger x2, Cola x2, Fries x1
   โต๊ะ T8: Pizza x1, Cola x2, Fries x1
5. ชำระเงินแยกกัน
```

### กรณีที่ 4: เปลี่ยนโต๊ะ (เมนูที่ส่งครัวแล้วไม่หาย)

```
โต๊ะ T2: 
- Main Course x2 (ส่งครัวแล้ว) ✅
- Dessert x1 (ยังไม่ส่งครัว)

ขั้นตอน:
1. คลิก "เปลี่ยนโต๊ะ"
2. ระบบถาม: "ล้างรายการปัจจุบันเพื่อเปลี่ยนโต๊ะ?"
3. คลิก "ตกลง"
4. ผลลัพธ์:
   - Dessert x1 ถูกล้าง (ยังไม่ส่งครัว)
   - Main Course x2 ยังคงอยู่ (ส่งครัวแล้ว) ✅
5. เลือกโต๊ะใหม่ T4
6. Main Course x2 ย้ายไปโต๊ะ T4
```

## ✅ ข้อดี (Benefits)

1. **เห็นรายการทั้งหมด** - เมนูที่ส่งครัวแล้วยังเห็นในตะกร้า
2. **ยืดหยุ่นมากขึ้น** - รวม/แยกโต๊ะได้ตามต้องการ
3. **ลดความผิดพลาด** - เห็นว่าส่งอะไรไปครัวแล้วบ้าง
4. **รองรับ Split Bill** - แยกบิลได้ง่าย
5. **รองรับ Merge Tables** - รวมโต๊ะได้สะดวก

---

## ⚠️ ข้อควรระวัง

1. **ส่งไปครัว** - เมนูจะไม่หาย ยังอยู่ในตะกร้า
2. **รวมโต๊ะ** - โต๊ะเดิมจะถูกปล่อยอัตโนมัติ
3. **แยกโต๊ะ** - ต้องเลือกรายการก่อนเลือกโต๊ะปลายทาง
4. **เมนูที่ส่งครัวแล้ว** - จะไม่ถูกล้างจนกว่าจะ Checkout
5. **Checkout** - จะล้างเมนูทั้งหมด (รวมที่ส่งครัวแล้ว)
