# คู่มือการใช้งานระบบโต๊ะ (Table Workflow Guide)

## ภาพรวม (Overview)

ระบบโต๊ะได้รับการปรับปรุงให้สามารถ:
1. **เข้าโต๊ะได้ตลอด** - แม้โต๊ะจะมีคนนั่งอยู่ก็สามารถเข้าไปเพิ่มเมนูได้
2. **สั่งเมนู** - เพิ่มเมนูได้ตลอดเวลา
3. **ออกโต๊ะเมื่อ Checkout** - ชำระเงินแล้วจึงปล่อยโต๊ะ
4. **โต๊ะว่างอัตโนมัติ** - ถ้าไม่มีเมนูในตะกร้า โต๊ะจะกลับเป็นว่างอัตโนมัติ

---

## 🔄 ขั้นตอนการใช้งาน (Workflow)

### 1. เข้าโต๊ะ (Select Table)

**วิธีเลือกโต๊ะ:**
- คลิกปุ่ม **"เลือกโต๊ะ"** (Select Table) ที่หน้า Menu
- หรือคลิก **"เปลี่ยนโต๊ะ"** (Change Table) ที่แถบด้านบน

**ตัวเลือก:**
- **Takeout** - สำหรับลูกค้าสั่งกลับบ้าน
- **Dine In** - เลือกโต๊ะสำหรับลูกค้านั่งทาน

**สถานะโต๊ะ:**
- 🟢 **Available** (ว่าง) - สามารถเลือกได้
- 🔴 **Occupied** (มีคนนั่ง) - **สามารถเลือกได้** (เพื่อเพิ่มเมนู)
- 🟡 **Reserved** (จองแล้ว) - ไม่สามารถเลือกได้
- ⚫ **Inactive** (ปิดใช้งาน) - ไม่สามารถเลือกได้

### 2. สั่งเมนู (Order Items)

หลังจากเลือกโต๊ะแล้ว:

1. **เลือกเมนู** จาก Tab "เมนู" (Menu)
2. **คลิกเมนู** เพื่อเพิ่มลงตะกร้า
3. **ปรับจำนวน** ด้วยปุ่ม + / -
4. **เพิ่มหมายเหตุ** (ถ้าต้องการ)

**การเพิ่มเมนูเพิ่มเติม:**
- สามารถกลับไปที่ Tab "เมนู" เพื่อเพิ่มเมนูได้ตลอดเวลา
- ไม่จำเป็นต้อง Hold Order
- เมนูที่เพิ่มจะรวมกับรายการเดิมในตะกร้า

### 3. เข้าโต๊ะซ้ำได้ (Re-enter Table)

**สามารถเข้าโต๊ะที่มีคนนั่งอยู่แล้วได้:**
1. คลิก **"เปลี่ยนโต๊ะ"** (Change Table)
2. เลือกโต๊ะที่มีสถานะ **Occupied** (แดง)
3. เพิ่มเมนูใหม่ได้เลย

**กรณีใช้งาน:**
- ลูกค้าสั่งเพิ่ม
- พนักงานคนอื่นต้องการเพิ่มเมนูให้โต๊ะเดียวกัน
- แก้ไขรายการก่อนชำระเงิน

### 4. ส่งไปครัว (Send to Kitchen) - ถ้าต้องการ

หากต้องการส่งรายการไปครัว:

1. คลิกปุ่ม **"ส่งไปครัว"** (Send to Kitchen)
2. รายการจะถูกส่งไปครัว
3. สามารถเพิ่มเมนูใหม่ต่อได้

**หมายเหตุ:**
- รายการที่ส่งไปครัวแล้วจะแสดงสถานะ "Sent to Kitchen"
- สามารถเพิ่มเมนูใหม่และส่งไปครัวอีกครั้งได้

### 5. ออกโต๊ะ (Checkout & Release Table)

เมื่อลูกค้าต้องการชำระเงิน:

1. คลิกปุ่ม **"ชำระเงิน"** (Checkout)
2. เลือกวิธีชำระเงิน:
   - **เงินสด** (Cash) - ระบุจำนวนเงินที่รับ
   - **โอนเงิน** (Transfer) - เลือกธนาคาร
3. คลิก **"ยืนยัน"** (Confirm)

**ผลลัพธ์:**
- ✅ บันทึกรายการสั่งซื้อ
- ✅ พิมพ์ใบเสร็จ (ถ้าเปิดใช้งาน Auto Print)
- ✅ **ปล่อยโต๊ะอัตโนมัติ** (สถานะกลับเป็น Available)
- ✅ พร้อมรับลูกค้าคนต่อไป

### 6. โต๊ะว่างอัตโนมัติ (Auto Release)

โต๊ะจะกลับเป็นว่างอัตโนมัติเมื่อ:
- ✅ ลบเมนูทั้งหมดออกจากตะกร้า
- ✅ ล้างตะกร้า (Clear Cart)
- ✅ ชำระเงินเสร็จ (Checkout)

## 🔧 ฟีเจอร์เพิ่มเติม (Additional Features)

### เปลี่ยนโต๊ะ (Change Table)

หากต้องการเปลี่ยนโต๊ะระหว่างสั่ง:

1. คลิกปุ่ม **"เปลี่ยนโต๊ะ"** (Change Table) ที่แถบด้านบน
2. ระบบจะถามว่าต้องการล้างรายการปัจจุบันหรือไม่
3. เลือกโต๊ะใหม่ (สามารถเลือกโต๊ะที่ Occupied ได้)

### พักรายการ (Hold Order)

หากต้องการพักรายการไว้ก่อน:

1. คลิกปุ่ม **"พักรายการ"** (Hold Order)
2. รายการจะถูกบันทึกไว้ใน Tab "Takeout / Held Orders"
3. สามารถกลับมาดำเนินการต่อได้ภายหลัง

### ล้างตะกร้า (Clear Cart)

หากต้องการล้างรายการทั้งหมด:

1. คลิกปุ่ม **ถังขยะ** (Trash) ที่มุมบนขวาของตะกร้า
2. รายการทั้งหมดจะถูกลบ
3. **โต๊ะจะกลับเป็นว่างอัตโนมัติ**

## 📊 สถานะโต๊ะ (Table Status)

| สถานะ | สี | คำอธิบาย | สามารถเลือกได้ |
|-------|-----|----------|----------------|
| **Available** | 🟢 เขียว | โต๊ะว่าง พร้อมใช้งาน | ✅ ได้ |
| **Occupied** | 🔴 แดง | มีลูกค้านั่งอยู่ | ✅ ได้ (เพื่อเพิ่มเมนู) |
| **Reserved** | 🟡 เหลือง | โต๊ะถูกจองไว้ | ❌ ไม่ได้ |
| **Inactive** | ⚫ เทา | โต๊ะปิดใช้งาน | ❌ ไม่ได้ |

## 🎯 ข้อดีของระบบใหม่ (Benefits)

1. **เข้าโต๊ะได้ตลอด** - แม้โต๊ะจะมีคนนั่งอยู่
2. **เพิ่มเมนูได้ตลอด** - ไม่ต้อง Hold Order
3. **ปล่อยโต๊ะอัตโนมัติ** - เมื่อชำระเงินหรือตะกร้าว่าง
4. **ติดตามสถานะโต๊ะ** - รู้ว่าโต๊ะไหนว่าง/ไม่ว่าง
5. **รองรับ Takeout** - สำหรับลูกค้าสั่งกลับบ้าน
6. **แสดงข้อมูลโต๊ะ** - เลขโต๊ะ, จำนวนที่นั่ง, โซน
7. **ยืดหยุ่น** - หลายคนสามารถเข้าโต๊ะเดียวกันได้

## 🔍 ตัวอย่างการใช้งาน (Example Usage)

### กรณีที่ 1: ลูกค้านั่งทาน (Dine-In)

```
1. คลิก "เลือกโต๊ะ" → เลือกโต๊ะ T1 (4 ที่นั่ง, Indoor)
2. สั่งเมนู: Burger x2, Cola x2
3. ลูกค้าสั่งเพิ่ม: Fries x1
   → กลับไปที่ Tab "เมนู" → เลือก Fries
4. ชำระเงิน: เงินสด 500 บาท
5. ระบบปล่อยโต๊ะ T1 อัตโนมัติ
```

### กรณีที่ 2: เข้าโต๊ะซ้ำ (Re-enter Occupied Table)

```
1. โต๊ะ T5 มีลูกค้านั่งอยู่ (สถานะ Occupied)
2. พนักงานคนอื่นต้องการเพิ่มเมนู
3. คลิก "เปลี่ยนโต๊ะ" → เลือกโต๊ะ T5 (แดง)
4. เพิ่มเมนู: Dessert x2
5. เมนูใหม่รวมกับรายการเดิม
6. ชำระเงินรวมทั้งหมด
```

### กรณีที่ 3: ลูกค้าสั่งกลับบ้าน (Takeout)

```
1. คลิก "เลือกโต๊ะ" → เลือก "Takeout"
2. สั่งเมนู: Pizza x1, Salad x1
3. ชำระเงิน: โอนเงิน (เลือกธนาคาร)
4. พิมพ์ใบเสร็จ
```

### กรณีที่ 4: ลบเมนูทั้งหมด (Auto Release)

```
1. เลือกโต๊ะ T3
2. สั่งเมนู: Coffee x1
3. ลูกค้าเปลี่ยนใจ → ลบเมนูออก
4. ระบบปล่อยโต๊ะ T3 อัตโนมัติ (กลับเป็น Available)
```

---

## ⚠️ ข้อควรระวัง (Important Notes)

1. **โต๊ะที่ Reserved** - ไม่สามารถเลือกได้
2. **โต๊ะที่ Occupied** - **สามารถเลือกได้** เพื่อเพิ่มเมนู
3. **การเปลี่ยนโต๊ะ** - จะล้างรายการปัจจุบัน
4. **การ Checkout** - จะปล่อยโต๊ะอัตโนมัติ (ไม่สามารถยกเลิกได้)
5. **ตะกร้าว่าง** - โต๊ะจะกลับเป็นว่างอัตโนมัติ
6. **Held Orders** - ไม่ได้ปล่อยโต๊ะ ต้อง Resume และ Checkout ก่อน
