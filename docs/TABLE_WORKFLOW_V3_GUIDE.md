# คู่มือการใช้งานระบบโต๊ะ เวอร์ชัน 3.0

## 🎯 ภาพรวม (Overview)

ระบบโต๊ะเวอร์ชัน 3.0 ได้รับการปรับปรุงใหม่ทั้งหมด:

### ✨ การเปลี่ยนแปลงหลัก

1. **แยก Dine-In และ Takeout เป็น 2 Tabs**
   - ไม่มีปุ่ม Takeout ใน modal อีกต่อไป
   - เลือกระหว่าง "นั่งทาน" หรือ "กลับบ้าน" ผ่าน Tabs

2. **ลบ "Takeout / Held Orders" Tab**
   - ไม่มี Tab สลับในหน้า POS อีกต่อไป
   - มีเฉพาะหน้าเมนูเดียว

3. **เปลี่ยนโต๊ะ = ล้างเมนูที่ยังไม่ส่งครัว**
   - เมื่อเปลี่ยนโต๊ะ จะล้างเฉพาะเมนูที่ยังไม่ส่งครัว
   - เมนูที่ส่งครัวแล้วจะยังคงอยู่

4. **ปุ่มกลับไปเลือก**
   - เพิ่มปุ่ม "กลับไปเลือก" เพื่อกลับไปหน้าเลือก Dine-In/Takeout
   - ล้างเมนูที่ยังไม่ส่งครัวอัตโนมัติ

---

## 🔄 ขั้นตอนการใช้งาน (Workflow)

### 1. เลือกประเภทการสั่ง (Select Order Type)

เมื่อเปิดหน้า POS หรือคลิก "เลือกโต๊ะ" จะแสดงหน้าต่างให้เลือก:

**2 Tabs:**
- 🍽️ **Dine-In** (นั่งทาน) - เลือกโต๊ะ
- 🛍️ **Takeout** (กลับบ้าน) - สั่งกลับบ้าน

### 2. Tab "Dine-In" (นั่งทาน)

**เลือกโต๊ะ:**
1. เลือก Zone (Indoor, Outdoor, VIP)
2. คลิกโต๊ะที่ต้องการ
3. เริ่มสั่งเมนู

**สถานะโต๊ะ:**
- 🟢 **Available** (ว่าง) - เลือกได้
- 🔴 **Occupied** (มีคนนั่ง) - เลือกได้ (เพื่อเพิ่มเมนู)
- 🟡 **Reserved** (จองแล้ว) - เลือกไม่ได้
- ⚫ **Inactive** (ปิดใช้งาน) - เลือกไม่ได้

### 3. Tab "Takeout" (กลับบ้าน)

**สั่งกลับบ้าน:**
1. คลิก Tab "Takeout"
2. คลิกปุ่ม "Takeout" ใหญ่
3. เริ่มสั่งเมนู

### 4. สั่งเมนู (Order Items)

หลังจากเลือกโต๊ะหรือ Takeout แล้ว:

1. **เลือกเมนู** จากรายการ
2. **คลิกเมนู** เพื่อเพิ่มลงตะกร้า
3. **ปรับจำนวน** ด้วยปุ่ม + / -
4. **เพิ่มหมายเหตุ** (ถ้าต้องการ)

### 5. ปุ่มควบคุม (Control Buttons)

**ที่แถบด้านบน:**
- 🔙 **กลับไปเลือก** - กลับไปหน้าเลือก Dine-In/Takeout (ล้างเมนูที่ยังไม่ส่งครัว)
- 🔄 **เปลี่ยนโต๊ะ** - เปลี่ยนโต๊ะ (ล้างเมนูที่ยังไม่ส่งครัว)

**ที่ตะกร้า:**
- ⏸️ **พักรายการ** - พักรายการไว้ก่อน
- 🗑️ **ล้างตะกร้า** - ล้างเมนูที่ยังไม่ส่งครัว

### 6. ส่งไปครัว (Send to Kitchen)

หากต้องการส่งรายการไปครัว:

1. คลิกปุ่ม **"ส่งไปครัว"**
2. รายการจะถูกส่งไปครัว
3. สามารถเพิ่มเมนูใหม่ต่อได้

**หมายเหตุ:**
- เมนูที่ส่งครัวแล้วจะไม่ถูกล้างเมื่อเปลี่ยนโต๊ะ
- เมนูที่ส่งครัวแล้วจะไม่ถูกล้างเมื่อกดปุ่ม "กลับไปเลือก"

### 7. ชำระเงิน (Checkout)

เมื่อลูกค้าต้องการชำระเงิน:

1. คลิกปุ่ม **"ชำระเงิน"**
2. เลือกวิธีชำระเงิน (เงินสด/โอนเงิน)
3. คลิก **"ยืนยัน"**

**ผลลัพธ์:**
- ✅ บันทึกรายการสั่งซื้อ
- ✅ พิมพ์ใบเสร็จ (ถ้าเปิดใช้งาน)
- ✅ ปล่อยโต๊ะอัตโนมัติ
- ✅ พร้อมรับลูกค้าคนต่อไป

## 🔍 ตัวอย่างการใช้งาน

### กรณีที่ 1: ลูกค้านั่งทาน

```
1. คลิก "เลือกโต๊ะ"
2. เลือก Tab "นั่งทาน"
3. เลือกโต๊ะ T1
4. สั่งเมนู: Burger x2, Cola x2
5. ส่งไปครัว
6. ลูกค้าสั่งเพิ่ม: Fries x1
7. ส่งไปครัวอีกครั้ง
8. ชำระเงิน
9. โต๊ะ T1 กลับเป็นว่างอัตโนมัติ
```

### กรณีที่ 2: เปลี่ยนโต๊ะ

```
1. โต๊ะ T5 มีเมนู: Appetizer x2 (ยังไม่ส่งครัว)
2. คลิก "เปลี่ยนโต๊ะ"
3. ระบบถาม: "ล้างรายการปัจจุบันเพื่อเปลี่ยนโต๊ะ?"
4. คลิก "ตกลง"
5. เมนูที่ยังไม่ส่งครัวถูกล้าง
6. เลือกโต๊ะ T3
7. สั่งเมนูใหม่
```

### กรณีที่ 3: กลับไปเลือกใหม่

```
1. โต๊ะ T2 มีเมนู: Main Course x2 (ส่งครัวแล้ว)
                    Dessert x1 (ยังไม่ส่งครัว)
2. คลิก "กลับไปเลือก"
3. เมนู Dessert ถูกล้าง (ยังไม่ส่งครัว)
4. เมนู Main Course ยังคงอยู่ (ส่งครัวแล้ว)
5. กลับไปหน้าเลือก Dine-In/Takeout
6. เลือก Tab "กลับบ้าน"
7. คลิก "Takeout"
8. สั่งเมนูใหม่
```

### กรณีที่ 4: สั่งกลับบ้าน

```
1. คลิก "เลือกโต๊ะ"
2. เลือก Tab "กลับบ้าน"
3. คลิกปุ่ม "Takeout"
4. สั่งเมนู: Pizza x1, Salad x1
5. ชำระเงิน
6. พิมพ์ใบเสร็จ
```

## ✅ ข้อดี (Benefits)

1. **UI สะอาดขึ้น** - ไม่มี Tabs ซับซ้อน
2. **เลือกง่ายขึ้น** - แยก Dine-In/Takeout ชัดเจน
3. **ยืดหยุ่นมากขึ้น** - กลับไปเลือกใหม่ได้ตลอด
4. **ปลอดภัยขึ้น** - เมนูที่ส่งครัวแล้วไม่ถูกล้าง
5. **ใช้งานง่าย** - ปุ่มควบคุมชัดเจน

---

## ⚠️ ข้อควรระวัง

1. **กลับไปเลือก** - จะล้างเมนูที่ยังไม่ส่งครัว
2. **เปลี่ยนโต๊ะ** - จะล้างเมนูที่ยังไม่ส่งครัว
3. **เมนูที่ส่งครัวแล้ว** - จะไม่ถูกล้างจนกว่าจะ Checkout
4. **Held Orders** - ยังคงใช้งานได้ผ่านปุ่ม "พักรายการ"
